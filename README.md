# Anime Scene Finder
Anime Scene Finder is a web appilication that allows users to search for anime scene and episode information while tracking and
visulizing search activity through interactive chart.

## Features
- Anime scene search
- Search history tracking
- Interactive chart visualization
- Simple and straight forward interface
- Data storage using Supabase

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Supabase
- Chart.js
- Vercel

## Installation

- Clone the repository:
```bash
git clone git@github.com:SZYua/INST377-FinalProject.git
```
- Install dependencies:
```bash
npm install
```
- Run the application
```bash
npm start
```

## Usage
1. Search for anime scenes or episode information
2. View search results
3. Track search history
4. Explore search analytics through charts
